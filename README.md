## How I like to build

I enjoy working across the full product loop:

1. Find a real problem.
2. Understand how people currently solve it.
3. Build the smallest useful version.
4. Test it with reality.
5. Improve the parts that matter.

Some days that means designing APIs and database schemas.  
Some days it means shaping a product workflow.  
Some days it means debugging an LLM that confidently misunderstood the assignment.

All of it is part of building.
